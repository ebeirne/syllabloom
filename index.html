ON THIS DEVICE

Send cards straight to Anki Desktop

Keep Anki Desktop open to add ready cards to your collection, then sync them through AnkiWeb. Your Anki password never goes through Syllabloom.

Anki Desktop is not connected on this device. The downloadable deck remains available above.

Set up Anki Desktop sync
  1. Install the AnkiConnect add-on in Anki Desktop, then restart Anki.
  2. In AnkiConnect settings, allow this exact site origin: https://syllabloom.study. Add http://localhost:4174 only if you use the local test site. Do not use a wildcard origin.
  3. Open Anki Desktop and sign into AnkiWeb there. Syllabloom sends cards to this computer; Anki handles cloud sync.
  4. Return here and check the connection. Sending works only while this computer has Anki Desktop open.
